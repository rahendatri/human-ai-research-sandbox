# human-ai-research-sandbox

With this project, create repeatable workspaces for running market research with an AI agent as your co-worker. The folder layout is fixed so every research project looks the same; the work inside evolves freely.

## Layout

```
./
├── input/           # Reference material you give the project (read-only for agents)
├── working-space/   # Your notes + things you shape with the agent together
└── output/          # Deliverables the agent produces (reports, dashboards, decks)
```

- **input/** — briefs, PDFs, exports, prior research. The agent reads these but never changes them.
- **working-space/** — messy-but-legible drafts, tables, and analyses. Some you write yourself, some you build with the agent.
- **output/** — polished artifacts generated by the agent. You give feedback through chat, the agent regenerates the file.

## How to use it

1. Clone this project
2. Drop source materials into `input/`.
3. Chat with the agent to work on the input files, create your own files in `working-space/`.
4. When you want a deliverable, ask the agent to produce it in `output/`.

On steps 3 and 4, you decide when to co-create vs. when to let the agent generate.
